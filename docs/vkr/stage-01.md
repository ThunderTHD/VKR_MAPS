# Этап 1. Архитектура и каркас — заметки для текста ВКР

**Что сделано.** Спроектирована архитектура системы и создан каркас: приложение на
FastAPI с REST API и автоматической документацией OpenAPI, база данных PostgreSQL 16
с расширением PostGIS 3.4, механизм миграций Alembic, автотесты на pytest, контейнерное
развёртывание Docker Compose и непрерывная интеграция GitHub Actions.

**Архитектурный стиль.** Выбран модульный монолит с разделением на слои (API, сервисы,
модели, ядро). Бизнес-логика сосредоточена в сервисном слое и не зависит от HTTP, что
позволяет тестировать алгоритмы трассировки, локализации и разбора ИД изолированно и
переиспользовать их в скриптах эксперимента. Микросервисная архитектура отвергнута
как избыточная при нагрузке в единицы–десятки пользователей.

**Хранение пространственных данных.** PostGIS обеспечивает вычисление длин по
эллипсоиду (тип geography), пространственную привязку объектов при импорте
(ST_DWithin) и интерполяцию точки на линии (ST_LineInterpolatePoint), необходимую для
отображения места повреждения. Единая система координат — WGS-84 (EPSG:4326),
совпадающая с KML и GPS мобильных устройств.

**Интерфейс.** Фронтенд реализуется на JavaScript (ES-модули) с библиотекой Leaflet
без этапа сборки — это упрощает развёртывание: на рабочей станции и сервере требуется
только Docker. Фреймворк Vue отвергнут как добавляющий инфраструктуру сборки без
существенной пользы для интерфейса «карта + формы».

**Модель данных.** Разработана ER-модель из пяти групп сущностей. Ключевые решения:
разделение инфраструктуры (трассы владельцев) и кабелей (операторов), нормализованное
хранение рассветки (основа графа сети), хранение источника и погрешности для каждой
длины (основа интервальной оценки места повреждения), фиксация происхождения каждого
объекта и журнал аудита.

**Качество.** Тесты выполняются на реальном PostGIS, а не на SQLite, поскольку ключевая
логика опирается на пространственные функции. Конфигурация через переменные окружения
позволяет без изменения кода переносить систему между ноутбуком и сервером компании.
