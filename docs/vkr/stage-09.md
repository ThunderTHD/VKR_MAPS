# Этап 9. Импорт пакетов ИД и проверка их качества — заметки для текста ВКР

**Что сделано.** Пакет исполнительной документации (один PDF на 15–50 страниц) загружается
через веб-интерфейс, разбирается в фоне, проверяется на согласованность, сопоставляется с
объектами сети и по подтверждению администратора переносит в систему данные, которых нет
ни в одной схеме: измеренную оптическую длину тракта, укрутку кабеля, приборы и сроки их
поверки, параметры узла доступа, координаты опор. Прототип разбора (этап 0) перенесён в
сервис `services/asbuilt`; правила распознавания страниц вынесены в `rules.yaml`.

**Разбор.** Тип страницы определяется по заголовку (первое совпавшее правило из YAML —
новую форму подрядчика можно поддержать без изменения кода). Из страниц с текстовым слоем
данные берутся из текста и таблиц (pdfplumber); страницы-сканы (свидетельства о поверке,
сертификаты) распознаются Tesseract (rus). Распознавание медленное (на реальном пакете из
48 страниц с 24 сканами — минуты), поэтому разбор идёт в фоновом потоке, а интерфейс
показывает ход работы; «зависшие» после перезапуска пакеты помечаются ошибкой.

**Проверки внутри пакета.** Номер ВОЛП и код объекта на всех страницах (по большинству);
длина кабеля в паспорте, на скелетной схеме, схеме прокладки, в отчёте по прокладке и
протоколе изоляции; сумма составляющих паспорта; участки + запасы = физическая длина;
пролёты по координатам опор против подписей на схеме; затухание против нормы протокола;
оптическая длина по рефлектометру и тестеру; нулевые потери на сварках («не заполнено»);
километрическое сопротивление изоляции; цвета волокон по стандартной маркировке; порты
тракта в акте ПНР и протоколе измерений; поверка приборов: найдено ли свидетельство,
совпадает ли заводской номер, не истёк ли срок на дату измерений.

**Результат на реальном пакете** (48 страниц, 24 скана; в репозиторий не входит): за 6 с
без OCR и ≈3,5 мин с OCR найдено 4 ошибки и 5 предупреждений, в том числе: страницы с
номером ВОЛП «/02» и чужим кодом объекта (скопированы из другого пакета), подпись длины
250 м на схеме при 220 м во всех документах, разные инициалы проверяющего, неверно
посчитанное километрическое сопротивление изоляции, затухание выше нормы, указанной в
том же протоколе, и **просроченная на дату измерений поверка рефлектометра** — то, что при
ручной приёмке легко пропустить.

**Сопоставление с сетью.** Кабель предлагается по номеру ВОЛП в названии; порты тракта —
по hostname коммутаторов из акта ПНР (узел доступа → узел → кросс с названием из акта →
номер порта). Сверка с системой: физическая длина кабеля (трасса + запасы) против ИД,
запасы, ёмкость по марке, и главное — проходит ли тракт в системе от порта A до порта Б
и совпадает ли его оптическая длина с измеренной. Несовпадение пути означает ошибку в
рассветке системы или в ИД — до записи данных.

**Подтверждение** (одна транзакция): измерение тракта с привязкой к пакету (эталон для
калибровки этапа 8); укрутка кабеля = опт./физ. длина − 1 с погрешностью от округления
длин до метра (≈0,82/L, 2σ) — калибровка такую укрутку не переписывает; приборы и
поверка; узел доступа (создаётся или обновляется); опоры по координатам (существующая
точка в 3 м используется повторно) и пролёты между ними; PDF прикрепляется к кабелю.

**Тестовые данные.** Реальные ИД содержат ФИО, IP-адреса и коды клиентов, поэтому для
тестов и демонстрации написан генератор синтетического пакета (reportlab): та же
структура документов с вымышленными данными и заложенными ошибками, включая скан
свидетельства о поверке (картинка без текста — проверяет ветку OCR). Пример лежит в
`data/samples/ИД_пример_синтетический.pdf`; проверка находит все заложенные ошибки.

**Качество.** 152 автотеста (добавлено 10): правила из YAML, сводка и типы страниц,
все заложенные ошибки (включая просроченную поверку при наличии OCR), предложения
сопоставления, сверка с системой (совпадение длины, несовпадение пути тракта), запись всех
видов данных, требование портов для измерения, повторное использование опор, отказ для
не-PDF, загрузка через API с фоновым разбором, права ролей, отклонение пакета.
