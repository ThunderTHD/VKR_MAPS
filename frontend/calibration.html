Калибровка модели длин

Уточнение укрутки кабелей и поправки «карта → реальная длина» по фактическим данным
Журнал повреждений Карта

Данные для калибровки: измерения трактов из ИД (оптическая длина между портами кроссов) и устранённые повреждения с отмеченным фактическим местом. По ним подбираются укрутка для каждой марки кабеля и общая поправка для участков, длина которых известна только по карте. Часть данных откладывается для проверки: параметры подбираются без неё, и сравнивается, насколько точнее предсказываются отложенные измерения. Расчёт ничего не меняет — изменения вступают в силу после кнопки «Применить», и их можно отменить.
