# Скрипты

| Скрипт | Назначение | Этап |
|---|---|---|
| `prototypes/id_parser.py` | прототип парсера пакета ИД (основа модуля `services/asbuilt`) | 9 |
| `generate_network.py` | генератор обезличенной тестовой сети | 2 |
| `anonymize.py` | обезличивание реальных KML и ИД для демонстрации | 12 |
| `experiment/` | расчёт метрик для главы с результатами | 12 |

Прототип парсера запускается отдельно: `python prototypes/id_parser.py ИД.pdf --out out --ocr`.
