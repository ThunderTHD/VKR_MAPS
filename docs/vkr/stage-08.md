# Этап 8. Журнал повреждений и калибровка — заметки для текста ВКР

**Что сделано.** Журнал повреждений: прогноз сохраняется вместе с точкой измерения; после
ремонта монтажник отмечает на карте фактическое место, система считает ошибку прогноза
по прямой и вдоль трассы и проверяет, попало ли место в интервал. Повреждения — слой на
карте (прогноз и факт, соединённые линией), отдельная страница журнала со сводкой точности.
Калибровка: по измерениям трактов из ИД и устранённым повреждениям уточняются укрутка
по маркам кабеля и поправка «реальная трасса длиннее нарисованной»; результат проверяется
до применения, применяется по кнопке администратора и может быть отменён.

**Ошибка «вдоль трассы».** Фактическое место проецируется на трассу волокна, по которой
делался прогноз (ближайшая точка ломаной в локальной метрике). Если тракт дважды
проходит одну канализацию (ответвление идёт назад вдоль магистрали), точка одинаково
близка к двум местам трассы; выбирается то, что ближе к прогнозу. Ошибка вдоль трассы
сравнивается с полушириной интервала — так копится статистика честности интервала на
реальных повреждениях.

**Модель калибровки.** Для наблюдения (измеренная оптическая длина D до известной точки):
D = Σ_t (1 + k_t)·(K_t + (1 + s)·G_t) + ε, где t — марка кабеля, K_t — известные длины,
G_t — длины «по карте», k_t — укрутка марки, s — поправка карты. Укрутка оценивается по
маркам, а не по отдельным кабелям: это свойство конструкции кабеля, а данных на каждый
кабель обычно мало. Ошибка ε учитывает погрешности известных длин, прибора и разброс
поправки карты от участка к участку (τ), который оценивается по остаткам (метод моментов).

**Метод оценки.** Наименьшие квадраты с весами 1/σ² и априорными значениями
(регуляризация Тихонова — оценка максимума апостериорной вероятности при нормальных
ошибках): параметры, по которым данных мало, остаются у типовых значений. Модель
нелинейна (произведение множителей), решается методом Гаусса–Ньютона (сходится за 3–5
итераций). Обратная матрица (JᵀWJ + P)⁻¹ даёт погрешность каждого параметра; укрутка
марки предлагается к изменению, только если её погрешность уменьшилась хотя бы до 75 %
априорной. После применения у кабелей сохраняется погрешность укрутки, а у длин «по карте»
— новая погрешность (2τ); локализация использует их вместо значений по умолчанию, поэтому
интервал сужается.

**Проверка.** (1) Отложенная выборка: 30 % наблюдений не участвуют в подборе; сравнивается
ошибка предсказания их длины до и после. (2) На сгенерированной сети — моделирование 200
повреждений до и после (применение выполняется во временной точке сохранения и
откатывается — расчёт ничего не меняет в базе).

**Результаты на тестовой сети** (21 измерение ИД + 41 устранённое повреждение):
поправка карты +8,9 % ± 1,6 % (истинная — 3–25 % в зависимости от типа трассы);
отложенная выборка: RMSE 45,4 → 12,9 м, систематический сдвиг 35,2 → 6,8 м;
моделирование: средняя ошибка места 20,8 → 6,6 м, медиана 17,4 → 4,0 м, 90 % ошибок
не больше 45,1 → 16,7 м, интервал ±40,7 → ±25,3 м при попадании 99 → 99,5 %.
Укрутка и поправка карты частично взаимозаменяемы (обе удлиняют оптический путь), поэтому
оценки отдельных параметров менее точны, чем их совместный эффект; проверяется именно
точность предсказания — она и важна для локализации.

**Качество.** 142 автотеста (добавлено 7): фактическое место и обе ошибки, отмена и
возврат в работу, проекция при двойном проходе трассы, недостаток данных, калибровка на
сгенерированной сети (поправка в ожидаемых пределах, улучшение на отложенной выборке и в
моделировании, расчёт не меняет базу, применение и откат), учёт калибровки трассировкой,
API и права ролей.
