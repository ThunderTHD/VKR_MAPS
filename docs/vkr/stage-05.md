# Этап 5. Рисование на карте и прокладка кабеля по трассе — заметки для текста ВКР

**Что сделано.** Инструменты администратора на карте: новая точка сети; рисование участков
трасс цепочкой от колодца к колодцу с привязкой к существующим точкам; изменение формы
участка перетаскиванием изгибов; вставка колодца в существующий участок; прокладка кабеля
по трассам щелчками по начальной, промежуточным и конечной точкам с предпросмотром пути и
длины; правка, перекладка и удаление кабеля. Команда очистки тестовой сети генератора
(`clear-generated`, `clear_test_data.bat`), не затрагивающая импортированные данные.

**Модель «трасса отдельно, кабель отдельно».** Кабель не рисуется линией: он ссылается на
упорядоченную цепочку участков трасс с направлением прохода (+1/−1). Геометрия кабеля —
производная, собирается в PostGIS из участков. Поэтому изменение формы трассы, перенос
колодца или вставка точки автоматически меняют все кабели, проходящие по участку, а длина
кабеля всегда согласована с длинами участков.

**Поиск пути.** Граф трасс (NetworkX, MultiGraph — между двумя колодцами бывает несколько
канализаций): вершины — точки сети, рёбра — участки, вес — лучшая известная длина
(фактическая, иначе по карте). Между соседними опорными точками ищется кратчайший путь
(алгоритм Дейкстры), отрезки склеиваются. Опорные точки нужны, когда кабель идёт не
кратчайшим путём. Ответ предпросмотра сообщает, у скольких участков пути длина известна
только по карте, — это заранее показывает пользователю качество будущей локализации.

**Привязка при рисовании — двухуровневая.** Интерфейс прилипает к точкам по экранному
расстоянию (15 пикселей), что удобно при любом масштабе; сервер дополнительно ищет точку в
радиусе 3 м по эллипсоиду (`ST_DWithin` по geography) и использует её вместо создания
дубля. Концы участка всегда совпадают с координатами точек сети: топология остаётся без
зазоров, которые на этапе 4 приходилось исправлять при импорте.

**Вставка точки в участок** (`ST_LineLocatePoint`, `ST_LineSubstring`): участок делится в
ближайшей к щелчку позиции; исходный участок сохраняет идентификатор и историю,
фактическая длина делится пропорционально с тем же источником, а в маршрутах кабелей
второй участок вставляется с учётом направления прохода — порядок маршрута не нарушается.

**Ограничения целостности.** Кабель нельзя удалить или сменить ему концы, если его волокна
сварены в муфтах или заведены на кросс; марку кабеля сменить нельзя (от неё зависят
волокна). Маршрут, проходящий участок дважды, отклоняется. Каждая операция пишется в
журнал изменений.

**Качество.** 112 автотестов (добавлено 15): кратчайший путь и направления, опорные точки,
влияние фактической длины на выбор пути, понятная ошибка при отсутствии пути, создание
кабеля с волокнами, маршрутом, запасами и непрерывной геометрией, перекладка, привязка
концов рисуемого участка, изменение формы с пересчётом кабелей, вставка точки в участок с
кабелями в обоих направлениях, очистка тестовой сети, API и права доступа. Интерфейс
проверен автоматизированным сценарием в браузере (Playwright) на ПК и телефоне.
