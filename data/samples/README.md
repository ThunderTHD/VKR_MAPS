# Примеры данных

Здесь лежат только **обезличенные или сгенерированные** данные: сдвинутые координаты,
заменённые коды узлов, ФИО, IP-адреса и коды клиентов.

Реальные выгрузки и пакеты ИД храните вне репозитория (например, в `data/real/` —
эта папка исключена из git).

`ИД_пример_синтетический.pdf` — синтетический пакет исполнительной документации
(генерируется `backend/tests/asbuilt_factory.py`): вымышленные данные и заложенные ошибки
для демонстрации раздела «Пакеты ИД».
