# Этап 2. Модель данных, справочники, генератор тестовой сети — заметки для текста ВКР

**Что сделано.** Реализована физическая модель данных из 32 таблиц (ORM SQLAlchemy 2 +
GeoAlchemy2), две миграции Alembic (схема; правила целостности и справочники),
справочники, хэширование паролей, генератор обезличенной тестовой сети и команды
обслуживания (`python -m app.cli`).

**Целостность рассветки на уровне СУБД.** Каждое волокно имеет два конца: `a` (у начала
кабеля) и `b` (у конца). Правило «конец волокна подключён не более одного раза — сваркой
или портом кросса» реализовано триггерами PL/pgSQL на таблицах `splice` и `cross_port`.
Поэтому некорректная рассветка не может попасть в базу ни через API, ни через импорт, ни
через прямой SQL. Дополнительно ограничения CHECK запрещают сварку волокна с самим собой,
сварку «нигде» (ни в муфте, ни в кроссе) и фактическую длину участка без указания её
источника.

**Справочники.** Источники длин с погрешностью по умолчанию (рефлектометр 1 %,
исполнительная документация 2 %, паспорт 5 %, со слов инженера 10 %, геометрия 25 %);
владельцы инфраструктуры и операторы; схемы цветовой маркировки (типовая восьмицветная с
красным счётным модулем, TIA-598 на 12 цветов); типовые марки кабеля с модульной
структурой. Цвета волокон вычисляются по марке: например, для ДПО-П-08У (2×4) волокно 3
модуля 1 — зелёное, что совпадает с исполнительной документацией реального объекта.

**Генератор тестовой сети** строит связную сеть условного района (около 260 точек,
370 участков, 50 кабелей, 1400 волокон, 860 сварок): канализацию нескольких владельцев,
линии опор, узлы четырёх операторов, магистрали, разрезанные муфтами, ответвления к
зданиям, кроссы, коммутаторы с вышестоящим узлом, измерения трактов. Сеть
воспроизводима (параметр `seed`) и полностью вымышлена — пригодна для демонстрации и
публикации.

**Методическая особенность — «истина» для эксперимента.** Генератор знает истинную длину
каждого участка и запаса и истинный коэффициент укрутки каждого кабеля (таблица
`sim_truth`), а в рабочие поля записывает значения с ошибкой, соответствующей источнику
длины. Средняя ошибка записанных длин: рефлектометр 0,4 %, ИД 0,7 %, паспорт 2 %, «со
слов» 4 %, по геометрии 6,8 %. Это позволяет в экспериментальной части объективно
измерить точность локализации повреждения и эффект калибровки: прогноз системы
сравнивается с истинным значением, которого система не видит.

**Безопасность.** Пароли хранятся как хэш scrypt с индивидуальной солью; проверка
выполняется сравнением за постоянное время.

**Качество.** 20 автотестов: соответствие миграций моделям (если модель изменена без
миграции — тест падает), справочники, цвета волокон, отказ базы при повторном подключении
конца волокна, связность сгенерированной сети, непрерывность маршрутов кабелей,
трассируемость каждого узла доступа до узла оператора, близость измерений к истине,
воспроизводимость генерации.
