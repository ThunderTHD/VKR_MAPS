# Этап 7. Трассировка волокна и локализация повреждения — заметки для текста ВКР

**Что сделано.** Трассировка волокна по сваркам от порта кросса (или от конца волокна
кабеля); список ожидаемых событий рефлектограммы (муфты, порты) с оптическими
расстояниями; локализация повреждения по показанию рефлектометра с интервалом
погрешности и разбором её источников; двусторонняя локализация; сохранение повреждения;
вычислительный эксперимент на сгенерированной сети. Инструмент «Повреждение» доступен
всем пользователям; сохранять повреждения могут монтажник и администратор.

**Трассировка (алгоритм).** Свет входит в волокно с одного конца и выходит с другого.
На выходном конце ищется сварка с этим концом (переход в следующее волокно) или порт
кросса (конец тракта); если нет ни того, ни другого — конец описания трассы. Проход
линейный по числу кабелей тракта; посещённые концы запоминаются, поэтому ошибочная
рассветка с петлёй не зацикливает алгоритм. Для каждого кабеля строится профиль в
направлении света: запасы в узлах и участки трасс с геометрией, развёрнутой по ходу
света (участок мог быть нарисован в обратную сторону).

**Модель длины.** Оптическая длина элемента L_опт = L · (1 + k), где L — лучшая
известная физическая длина (фактическая из источника либо по карте), k — коэффициент
укрутки кабеля. Повреждение в запасе ставится в узел, где лежит запас. Внутри участка
точка ставится пропорционально: доля по «паспортной» длине переносится на нарисованную
линию — так расхождение карты и реальной длины не сдвигает точку за пределы участка.
Учтены поправки прибора: длина измерительного шнура и пересчёт при неверно выставленном
показателе преломления D = D_пр · n_пр / n_вол.

**Интервал погрешности.** Ошибки длин пройденных элементов независимы и задаются
источником (рефлектометр 1 %, ИД 2 %, паспорт 5 %, со слов 10 %, по карте 25 %, как
2σ); ошибка укрутки одна на кабель (внутри кабеля ошибки коррелированы, поэтому
суммируется длина, а не дисперсии); погрешность прибора ±(1 м + 5·10⁻⁵·D). Дисперсии
складываются, полуширина h = 2·√Σσ². Вклад каждого источника показывается
пользователю — это прямо указывает, какую длину уточнить, чтобы интервал сузился.

**Двусторонняя локализация.** Оценки с двух концов тракта объединяются с весами 1/σ²;
поскольку каждая оценка точнее вблизи своего прибора, объединённый интервал уже
любого из двух. Если оценки расходятся больше суммарной погрешности — это признак
ошибки в длинах или рассветке, система предупреждает.

**Эксперимент (команда `localize-experiment`).** На сгенерированной сети (36 трактов
«узел связи → здание») смоделировано 500 повреждений: истинное показание рефлектометра
вычислено по истинным длинам и укрутке с шумом прибора, локализация — по рабочим
(неточным) данным. Результат до калибровки: средняя ошибка 20,5 м, медиана 15,8 м,
90 % случаев — не более 46,9 м; средняя полуширина интервала 39,2 м; истинная точка
попала в интервал в 98,8 % случаев (ожидается ≈95 %), то есть интервал честный, но с
запасом. Основные источники ошибки — участки с длиной только по карте (реальная трасса
на 3–12 % длиннее нарисованной — систематический сдвиг) и укрутка, записанная по
умолчанию 0,5 % при реальных 0,4–1,2 %. Именно эти систематические ошибки устраняет
калибровка на этапе 8.

**Качество.** 135 автотестов (добавлено 13): профиль тракта и разворот геометрии,
зеркальность трассы с другого конца, точка внутри участка и в запасе, поправки шнура и
показателя преломления, показание больше длины тракта, рост интервала при неточных
длинах, двусторонняя оценка и выявление несогласованности, прохождение через сварку
после разреза кабеля, незамкнутый тракт, колодцы в интервале, геометрические функции,
эксперимент на сгенерированной сети (покрытие интервала ≥ 85 %), API и права.
